เผยแพร่ Portfolio ออนไลน์ของคุณเพื่อให้มหาวิทยาลัยเข้าชมได้ทันที

1

เซฟไฟล์ HTML

บันทึกไฟล์โค้ดนี้ลงในคอมพิวเตอร์ โดยตั้งชื่อไฟล์ว่า index.html

2

สร้าง Repository

ล็อกอิน GitHub.com → กดสร้าง Repository ใหม่ เช่น ชื่อ portfolio-yammie (ตั้งเป็น Public)

3

อัปโหลดไฟล์

คลิก "uploading an existing file" ลากไฟล์ index.html ใส่เข้าไปแล้วกด Commit changes

4

เปิด GitHub Pages

ไปที่ Settings → Pages → ตรง Branch เลือก main หรือ root แล้วกด Save ได้ลิงก์ใช้งานทันที!

คำแนะนำสำหรับรูปภาพ: สามารถเปลี่ยน URL รูปภาพเกียรติบัตรหรือรูปส่วนตัวโดยฝากรูปไว้ที่เว็บอย่าง Imgur หรือนำรูปภาพใส่โฟลเดอร์เดียวกันใน GitHub แล้วเปลี่ยนชื่อไฟล์ใน โค้ดได้เลยค่ะ
